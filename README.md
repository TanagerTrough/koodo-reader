# Koodo Reader

📚 A modern ebook manager and reader with sync and backup capacities for Windows, macOS, Linux, Android, iOS, and Web.

## Overview

Koodo Reader is an ebook management and reading application designed for people who want a modern way to organize and read digital books across multiple platforms. It combines ebook reading with library management, while also offering sync and backup capabilities for users who need access to their reading environment on different devices.

The project is positioned as a cross-platform ebook reader and manager, supporting desktop systems such as Windows, macOS, and Linux, as well as Android, iOS, and Web access. This makes it suitable for readers who move between computers, phones, tablets, and browsers and want a more consistent experience.
